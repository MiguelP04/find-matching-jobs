- Proyecto: frontend de Find Matching Jobs.
- Stack: Next.js (App Router, v16), React 19, TypeScript, Tailwind CSS v4.
- Propósito: UI pública, autenticación y dashboard para estudiantes; componentes y hooks para consumir el backend y mostrar emparejamientos.

4. Flujo de datos y estado
- `src/lib/api.ts` define `api.get` y `api.post` con manejo de errores:
  - Usa `NEXT_PUBLIC_API_URL` o `http://localhost:3000` por defecto.
  - Intenta parsear JSON y tolera respuestas no-JSON (`.catch(() => null)`). Detecta `fieldErrors` en `body` o en `body.message` y lanza `ApiError` con `fieldErrors`.
  - Usa `cache: "no-store"` para evitar caches en fetch.
- `src/stores/authStore.ts`:
  - Persistencia en `localStorage` (middleware `persist` de zustand), key `auth-storage`, y `partialize` para guardar sólo lo necesario.
  - Estado: `user`, `accessToken`, `isAuthenticated`, `isLoading`, `error`.
  - Métodos: `login(email,password)` -> POST `/auth/login` ; `register(userData: RegisterDto)` -> POST `/auth/register`.
  - `setAuth(auth)`, `logout()`, `clearError()` y `checkAuth()` que valida token contra `/profiles/me` y actualiza estado.

5. DTOs y tipado
- El frontend consume tipos desde el paquete compartido `@find-matching-jobs/types` (p. ej. `LoginDto`, `RegisterDto`, `AuthResponseDto`).
- `authStore` y formularios utilizan esos DTOs: `RegisterDto` en `register`, `LoginDto` en el formulario de login.
- `useDashboard` define tipos locales `Profile` y `StudentSkill` para consumir `/profiles/me` y `/student-skills/me`.

6. Endpoints usados/esperados (backend)
- POST `/auth/login` -> responde `AuthResponseDto` con `access_token` y `user`.
- POST `/auth/register` -> crea usuario (acepta `RegisterDto`).
- GET/redirect `/auth/google` -> inicia OAuth con Google (frontend redirige al backend).
- GET `/profiles/me` -> usado por `authStore.checkAuth()` y `useDashboard` (debe devolver la estructura esperada: `{ user: {...}, ... }` o similar).
- GET `/student-skills/me` -> usado por `useDashboard` para cargar skills del usuario.
- Otros endpoints esperados: `/matching`, `/jobs` (frontend aún pendiente de consumirlos).
