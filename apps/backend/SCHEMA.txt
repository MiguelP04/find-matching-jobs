1. Resumen
- Proyecto: backend de Find Matching Jobs.
- Stack: NestJS (v11), TypeScript, TypeORM, PostgreSQL, Passport (JWT + Google OAuth).
- Propósito: API REST para gestionar usuarios, perfiles, skills, jobs y la lógica de matching entre estudiantes y vacantes.

6. Autenticación y autorización
- Passport con JWT: `jwt.strategy.ts` y `passport-jwt` para validar tokens en guardias (`jwt-auth.guard.ts`).
- Google OAuth: `passport-google-oauth20` con `google.strategy.ts` y rutas para iniciar OAuth y callback.
- Roles: `roles.decorator.ts` y `roles.guard.ts` para protección basada en roles.

7. Endpoints y contratos esperados (resumen)
- Auth
  - POST `/auth/login` -> login con email/password (devuelve `AuthResponseDto` con `access_token` y `user`).
  - POST `/auth/register` -> registro de usuario.
  - GET `/auth/google` -> iniciar OAuth con Google (redirect)
  - GET `/auth/google/callback` -> callback de OAuth (posible sesión/creación de usuario)
- Users
  - CRUD / endpoints para gestión de usuarios en `users.controller.ts`.
- Profiles
  - Endpoints para crear/actualizar perfiles (`profiles.controller.ts`).
- Skills, Jobs, Matching
  - Endpoints en sus respectivos módulos; matching ejecuta la lógica para emparejar candidatos y vacantes.
